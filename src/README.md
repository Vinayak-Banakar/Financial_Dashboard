# Data Directory

This directory contains the data files used by the Financial Dashboard application. These files are essential for powering the dashboard's visualizations, reports, and financial calculations.

## Contents

- **`dataset1.csv`**: Contains transaction records such as income and expenses over a specific period.
- **`dataset2.csv`**: Contains budget allocation details for different categories.
- **`exchange_rates.json`**: Historical exchange rate data used for currency conversions and financial analysis.

## Usage

These data files are imported into the application and used to generate various visualizations such as:

- Income vs Expense graphs
- Budget vs Actual reports
- Currency conversion charts

Ensure the data files are updated regularly to keep the dashboard information accurate and relevant.

## Notes

- Do not modify file names unless referenced accordingly in the application code.
- Ensure proper formatting (CSV or JSON) is maintained to avoid runtime errors.
